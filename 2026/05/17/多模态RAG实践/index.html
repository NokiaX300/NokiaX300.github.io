RAG 与知识系统

多模态 RAG 不只是给图片写摘要

从图像检索、知识图谱到多格式文档处理，梳理 Beyond Text、LightRAG 与 RAG-Anything 的工程边界

发布于 2026.05.17 更新于 2026.08.12 约 5 分钟

传统 RAG 往往先把 PDF 转成纯文本，再进行分块和向量检索。可一旦遇到流程图、原始界面图、表格和公式，这条链路就会丢失大量信息。

多模态 RAG 的目标并不是简单地把图片塞进上下文，而是让不同模态都成为可检索、可定位、可回到原始证据的知识对象。

在阅读和实践中，我把相关方案分成三条路线：图像检索、关系检索和多格式文档处理。

一、三类方案分别解决什么问题

方案 主要方向 核心机制 适合解决的问题
Beyond Text 图像参与检索 图像嵌入或图像摘要 如何让图表、截图被问题召回
LightRAG 关系与全局检索 实体、关系、图结构和向量检索 如何回答跨文档关系与主题问题
RAG-Anything 多格式统一处理 文档解析、多模态描述与混合检索 如何接入文本、图片、表格和公式

三者并不互斥。在完整系统中，文档解析负责拆出多模态元素，摘要或嵌入负责召回，知识图谱负责关系检索，最后再把原始证据交给模型。

二、图像摘要和图像嵌入怎么选

让图像进入检索系统，通常有两条路径：

直接生成多模态向量

图像通过视觉编码器生成向量，与文本查询进行跨模态相似度比较。优点是保留视觉表达，难点是查询与图像是否处于足够一致的向量空间。

先生成图像摘要，再做文本向量

视觉模型先把图片转成面向检索的文字描述，再复用成熟的文本嵌入链路。Beyond Text 的实验显示了图像摘要路线的潜力，但结果仍会受到数据集、视觉模型、摘要 Prompt 和评测方法影响。

Beyond Text 所采用的处理链可以写成可检索的文本流程：

无论选择哪条路线，都不能越过同一条底线：

摘要或向量只是检索代理，不能替代原始图片。

命中摘要后，系统仍应取回原图，让多模态模型结合文本证据与视觉对象作答。

三、图像元数据至少要保存什么

至少要保留文件、页码、原图路径、题注、摘要来源，以及是否使用回退路径。否则系统最终只能返回一段无法验证的描述。

图像摘要 Prompt 也不应追求文学性，而要服务检索：使用具体名称，描述关键对象、关系、数值和异常，不使用「左边这个」「如下图所示」等离开图片就失去意义的表达。

四、LightRAG 为什么引入知识图谱

普通向量检索擅长寻找与查询语义接近的片段；但面对「多个实体之间有什么关系」「一批文档反映了哪些共同主题」时，扁平分块很容易产生碎片化结果。

LightRAG 从文本块中抽取实体和关系，将图结构与向量检索结合。查询阶段可以同时关注：

  • 高层关键词：整体概念、主题与关系；
  • 低层关键词：具体实体、事实和专业术语。

这样可以分别覆盖全局关系和局部事实。

但知识图谱并不是免费能力。实体与关系抽取会增加模型调用、索引成本和更新复杂度。只有真实问题确实涉及跨实体、跨文档关系时，图结构才值得引入。

五、RAG-Anything 如何组织多格式文档

RAG-Anything 将文本、图片、表格和公式放进统一处理流水线：

如果原图缺失或无法读取，可以根据路径、题注和脚注构造文本回退，但必须给结果标记 fallback=true。文本回退只能保证流程继续运行，不能冒充真实的视觉识别结果。

六、我采用的工程链路

完整链路可以拆成六层：

  1. 解析层：恢复页面结构并提取原始资产；
  2. 描述层：为图片、表格和公式生成可检索描述；
  3. 索引层：分别建立文本、视觉代理和关系索引；
  4. 检索层：根据问题选择向量、关键词、图或混合检索；
  5. 证据层：把摘要映射回原文、原图和页码；
  6. 生成层：让模型只基于返回证据作答并给出引用。

不同模态可以分别建索引，但最终必须共享同一套来源标识。

七、多模态 RAG 应该怎样评测

如果只评价最终答案，就很难判断问题究竟出在解析、检索还是生成。因此至少要分开记录：

  • 文本、图片、表格的解析召回；
  • 图像摘要是否覆盖关键对象和数值；
  • 不同模态的 Recall@K；
  • 摘要命中后原始资产能否正确回取；
  • 引用页码和图表是否准确；
  • 单模态与多模态答案差异；
  • 延迟、显存和模型调用成本。

同时还应保留纯文本基线。只有加入视觉内容后，目标问题的结果能够稳定改善，额外的系统复杂度才有意义。

八、常见误区

  • 把 OCR 文本当成完整多模态理解；
  • 只存图像摘要，不保留原图；
  • 图片和正文使用不同 ID，无法回溯；
  • 所有查询都调用昂贵的视觉模型；
  • 图谱建得很大，却没有真实关系型问题；
  • 用文本回退生成的描述冒充视觉事实；
  • 只展示最终答案，不评估各阶段错误。

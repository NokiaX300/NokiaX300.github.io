注册 GitHub 账号并创建两个仓库

GitHub 是用来存放源码和部署网站的平台，需要创建 2 个仓库：

仓库类型 仓库名称 仓库权限 作用
源码仓库 自定义名称（如blog） 私有 存放 Hexo 项目的所有源文件
部署仓库 你的GitHub用户名.github.io 公开 存放编译后的静态网站文件，用于 GitHub Pages 部署

创建步骤：

  1. 登录 GitHub，点击右上角「New repository」；
  2. 先创建源码仓库：名称填blog，勾选「Private」，点击「Create repository」；
  3. 再创建部署仓库：名称必须填用户名.github.io（如NokiaX300.github.io），勾选「Public」，点击「Create repository」。

评论功能（Giscus，基于 GitHub Discussions）

Giscus 是免费评论系统，无需服务器，步骤如下：

步骤 1：开启仓库 Discussions

进入你的部署仓库（用户名.github.io） → 点击「Settings」→ 找到「Features」→ 勾选「Discussions」。

步骤 2：安装 Giscus 应用

  • 打开 Giscus 官网，安装 giscus app（在线安装到 GitHub）。

步骤 3：生成 Giscus 配置代码

在 Giscus 官网配置：

  • Repository：输入你的用户名/部署仓库名（如NokiaX300/NokiaX300.github.io）；
  • Discussion category：选择一个分类（如Announcements）；
  • Mapping：选择pathname；
  • 其他选项按需勾选，点击「Copy」复制生成的<script>代码。

把 Linux 开发环境装进 Windows：WSL2 安装、迁移与 Cursor 连接

本文涵盖 WSL2 的安装与初始化、在 Cursor 中连接 WSL 开发环境，以及将 Ubuntu 发行版从 C 盘迁移到 D 盘的完整流程，并附常用管理命令速查。

一、WSL 是什么

WSL（Windows Subsystem for Linux）是微软官方推出的 Linux 子系统，让你在 Windows 上直接运行原生 Linux 环境，无需模拟硬件，性能损耗极低，还能实现 Windows 与 Linux 之间的无缝互操作。

优先选择 WSL2：日常开发、容器化、Docker、学习 Linux、高 IO 场景，均建议使用 WSL2。这是目前微软主推的版本，兼容性与性能都更成熟。

四、常用命令速查

命令 说明
wsl -l -v 查看已安装的发行版及版本
wsl -d Ubuntu 进入指定发行版
wsl -d Ubuntu -u root 以 root 身份进入
wsl --shutdown 关闭所有 WSL 实例（修改配置后需执行）
wsl --set-default Ubuntu 设置默认发行版

小结

  • 开发场景优先使用 WSL2，安装后记得将默认版本设为 2。
  • 迁移发行版前务必 先导出备份，确认 .tar 文件完整后再注销原实例。
  • 默认用户需在 WSL 内通过 /etc/wsl.conf 配置，修改后执行 wsl --shutdown 使配置生效。
